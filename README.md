# bd1-redsocial-grupo6
# Red Social Estudiantil Pascualina

## Integrantes del equipo
- Julian Quintero Copete

## Descripción del caso

Este proyecto consiste en el diseño del modelo conceptual de base de datos 
(Entidad-Relación) para una red social estudiantil universitaria. La 
plataforma busca mejorar la comunicación e interacción entre estudiantes, 
permitiendo crear perfiles con intereses y habilidades, seguir a otros 
compañeros, publicar actualizaciones, crear y unirse a grupos de estudio 
o interés, y programar eventos académicos y sociales.

## Estructura del repositorio

- `Tarea1/Informe`: informe detallado (PDF) con el análisis de 
  requerimientos, entidades, atributos, relaciones y justificación del 
  modelo conceptual.
- `Tarea1/Video`: enlace al video de sustentación en YouTube.
